# 5.1 Backend Dockerfile

Status: open
Owner:
Source: tech-stack.md > Stack (Hosting)
Depends on: 1.3, 3.6

## Description
Write `backend/Dockerfile`: Python slim image, install requirements, copy app + kernels + cropped DEMs, run uvicorn on `$PORT`.

Data notes (from 1.1/1.3): copy only `data/kernels/` (~44 MB) and `data/dem/` (~334 MB). Exclude `data/raw/` (~950 MB of source PDS files) via `.dockerignore`. `meta.tm` holds an absolute path, so regenerate it inside the image with `python scripts/fetch_data.py kernels` (it skips the existing kernels and only rewrites `meta.tm`).

## Expected user interaction
`docker build` and `docker run -p 8000:8000` serve the API locally.

## Done when
- `GET /sites` and `POST /analyze` work from the container
