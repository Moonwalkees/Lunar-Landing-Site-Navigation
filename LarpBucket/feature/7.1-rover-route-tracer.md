# 7.1 Rover route tracer

Status: open
Owner:
Source: Extension features (team brainstorm, not yet in scope.md)

## Description
Trace a rover route across the terrain that optimises the key factors (sunlight, Earth visibility, battery). Takes rover speed as an input. Overlay vectors on the map showing the direction in which each key factor improves.

## Expected user interaction
User sets a start point and a rover speed. The bird's eye view shows a suggested route, plus arrows pointing towards better sun and Earth visibility.

## Done when
- Route is drawn for a given start point and speed
- Direction vectors for each key factor are shown on the map
