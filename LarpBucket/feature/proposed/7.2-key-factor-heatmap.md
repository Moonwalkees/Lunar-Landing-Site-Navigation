# 7.2 Heatmap of key factors

Status: proposed
Owner:
Source: Extension features (team brainstorm, not yet in scope.md)

## Description
Compute the key factors (sunlit %, Earth visibility %, etc.) over a grid of sites and show them as a heatmap. Could also be shown as a heightmap view, with the factor as height.

## Expected user interaction
User picks a key factor and sees it as a heatmap over the region, optionally switching to a heightmap view.

## Done when
- Heatmap of at least one key factor renders over the region
- User can switch between key factors
