# 7.3 Rover battery simulation and survivability

Status: proposed
Owner:
Source: Extension features (team brainstorm, not yet in scope.md)

## Description
Simulate a rover's battery over time. Inputs: speed, battery size, battery degradation rate. Answers "how long will my site/rover survive here?" and turns the answer into a survivability stat that can be visualised.

## Expected user interaction
User enters speed, battery size and degradation rate, and sees the battery level over time and a survivability stat (e.g. days survived).

## Done when
- Battery over time accounts for speed, size and degradation rate
- Survivability stat is shown and visualised
