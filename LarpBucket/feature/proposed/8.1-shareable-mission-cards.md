# 8.1 Shareable mission cards

Status: proposed
Owner:
Source: X-factors (team brainstorm, not yet in scope.md)

## Description
Capture a location/mission as a shareable "card". Possible forms: trading card, boarding pass or poster. Shows lat/lon plus sun and Earth visibility as stats, and the location as an image (possibly stylised with AI). Includes a URL or QR code so others can load the same state.

## Expected user interaction
User clicks share and gets a card image with the site's stats and a URL/QR that opens the app in the same state.

## Done when
- Card shows lat/lon, sun and Earth visibility and a location image
- URL/QR on the card restores the state
