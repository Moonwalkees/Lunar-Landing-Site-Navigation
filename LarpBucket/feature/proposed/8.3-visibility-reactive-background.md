# 8.3 Background reacts to Sun and Earth visibility

Status: proposed
Owner:
Source: X-factors (team brainstorm, not yet in scope.md)

## Description
Make the background depend on visibility at the scrubber time.
- Slightly lighter when the Sun is in view, darker when it is not.
- No static when Earth is in view, a small amount of static when it is not.

## Expected user interaction
As the scrubber moves, the background lightens/darkens with the Sun and gains/loses static with Earth.

## Done when
- Background brightness follows Sun visibility
- Static overlay follows Earth visibility
