# 4.8 Apply style tokens and type to the shell

Status: open
Owner:
Source: doc/style.md > Colour, Type, Dot grid and pixel size, Rendering rules
Style: doc/style.md
Depends on: 4.1

## Description
Restyle the existing placeholder shell in `frontend/` to the dot-matrix board style: replace the colour tokens in `styles.css` with the ones in `doc/style.md`, load Doto and Geist Mono, set `tabular-nums`, make panels, buttons and inputs square (no border radius), and use Doto for all board text at 18 px or larger. Do not add the 3D map, the board table or new panels here; those wait on the open decisions in `doc/style.md`.

## Expected user interaction
User opens the app and sees the same panels as before, now on a black background with Doto type, the new palette and square chrome.

## Done when
- Tokens match `doc/style.md > Colour`
- Doto is used for headings, readouts, buttons and labels, never below 18 px
- No border radius anywhere
- Layout still works at 400 px with no horizontal scroll
- `npm run build` passes
