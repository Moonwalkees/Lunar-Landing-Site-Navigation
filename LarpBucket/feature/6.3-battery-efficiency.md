# 6.3 Battery charge/discharge efficiency

Status: open
Owner:
Source: scope.md > Model (Battery)
Priority: medium
Depends on: 3.2

## Description
Extend `simulate_battery` with a round-trip efficiency parameter (default ~0.9, to be agreed with the team). Apply `sqrt(eta)` on charging and discharging, or equivalent. Keep `eta = 1.0` reproducing the plain `charge += (P - load) * dt` model.

## Why it is useful
Real batteries lose 10-20% per round trip, which matters most when charge and discharge cycle every lunar day.

## Impact of not having it
Battery minimum and survival are optimistic. Marginal sites that really fail show as surviving, which is the costlier mistake for mission planning.

## Expected user interaction
Caller can pass an efficiency (or use the default) and gets a slightly lower battery curve and minimum.

## Done when
- `eta = 1.0` matches the 3.2 results exactly
- Lower `eta` gives a lower or equal minimum charge
- Default value agreed and written in scope.md or tech-stack.md
