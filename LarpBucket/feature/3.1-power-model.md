# 3.1 Sun disc fraction and power

Status: open
Owner:
Source: scope.md > Model (disc fraction, power), Core 4 Metrics (Power)

## Description
In `backend/app/model.py`, add `disc_fraction(sun_el, skyline_el)` using `f = 1 - (acos(x) - x*sqrt(1-x^2))/pi`, `x = (sun_el - skyline_el)/0.267°`, clamping x to [-1, 1]. Add `power(sun_el, f, area, efficiency) = 1361 * area * efficiency * cos(sun_el) * f`. Derive Wh/day and % time sunlit.

## Expected user interaction
Caller passes Sun elevation, skyline elevation at the Sun's azimuth, and panel params; gets power in W per time step.

## Done when
- `disc_fraction` returns 0 / 0.5 / 1 at x = -1 / 0 / 1 and never NaN
- Unit tests in `backend/tests/test_model.py`
