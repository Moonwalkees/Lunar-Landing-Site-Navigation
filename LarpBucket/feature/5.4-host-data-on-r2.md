# 5.4 Host the finished DEMs on Cloudflare R2

Status: in-progress
Owner: Maddie
Source: tech-stack.md > Stack (Hosting)
Depends on: 5.1

## Description
Downloading and cropping the raw LOLA maps (~2.4 GB) during the Docker build took hours from the Dokploy server. Upload the finished GeoTIFFs (`ldem_85s_20m_crop.tif`, `ldem_64.tif`, ~370 MB) to a public Cloudflare R2 bucket and let `fetch_data.py dems` download them from `DATA_URL` when it is set.

## Expected user interaction
Deploying the backend on any host builds in a couple of minutes with no manual data copying.

## Done when
- `DATA_URL` set: `fetch_data.py dems` downloads the two `.tif` files from it and skips the raw NASA download
- `DATA_URL` unset: behaviour is unchanged
- Backend Dockerfile takes `DATA_URL` as a build arg and the image serves `/analyze` on Dokploy
