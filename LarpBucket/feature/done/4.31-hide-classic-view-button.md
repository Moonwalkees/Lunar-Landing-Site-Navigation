# 4.31 Remove the CLASSIC VIEW button from the board

Status: done
Owner: Maddie
Note: Removed the CLASSIC VIEW button from the board; the classic UI is still reachable with ?ui=classic.
Source: user request 2026-11-15; follows 4.22

## Description
The board (the default UI) shows a CLASSIC VIEW button at the top-right. Remove it so the board no longer advertises the old UI. The classic UI itself stays in the build and can still be reached with `?ui=classic` or `VITE_UI=classic`, and it keeps its BOARD VIEW button to get back.

## Expected user interaction
The board's top-right shows only the clock stats; there is no CLASSIC VIEW button. Opening `?ui=classic` still shows the classic UI with a BOARD VIEW button.

## Done when
- No CLASSIC VIEW button on the board
- `?ui=classic` still loads the classic UI, and its BOARD VIEW button still returns to the board
- README and doc/style.md no longer say the board has the button
- `npm run build` passes

## Solution
**Chosen:** Dropped `<UiSwitch />` and its import from `frontend/src/board/BoardApp.tsx`. `src/UiSwitch.tsx`, `src/uiChoice.ts` and the classic UI are untouched, so `?ui=classic` and `VITE_UI=classic` still work and classic keeps its BOARD VIEW button. README, doc/style.md and doc/tech-stack.md now describe this. Checked in a browser: no CLASSIC VIEW on the board, `?ui=classic` loads classic, BOARD VIEW returns to `?ui=board`; `npm run build` passes.

**Strengths**
- Smallest change that does what was asked, and fully reversible by putting the one line back.
- Keeps the classic UI as a fallback and for anyone with a saved classic choice.

**Limitations**
- A visitor whose browser remembered "classic" (4.22) still opens classic until they use its BOARD VIEW button or `?ui=board`.
- The classic UI and Plotly chunk still ship in every build.

**Alternatives considered**
| Option | Why not chosen | Trade-off vs chosen |
|---|---|---|
| Delete the classic UI entirely (App.tsx, components, Plotly) | Much larger and not reversible in one line; not clearly what was asked | Smaller bundle and less code to maintain |
| Hide the button with CSS | Leaves dead markup in the page | No code change to BoardApp |
