# 4.13 Hollow Sun / Earth disc on the skyline when hidden

Status: done
Owner: Maddie
Note: done. `disc()` in `frontend/src/board/Skyline.tsx` strokes a hollow ring when the body is hidden.
Source: scope.md > Core 3 (horizon panorama); doc/style.md > Rendering rules (Sun and Earth discs never dithered)

## Description
On the board's horizon panel (`frontend/src/board/Skyline.tsx`) the Sun and Earth "now" discs are always solid, even when the body is below the skyline. Draw the disc hollow (an outline ring in the same colour) when the body is not visible, and solid when it is. This keeps the "never dithered" rule while showing visibility at a glance.

Visibility uses the same rule as the backend metrics:
- Sun visible: `sun.fraction[i] > 0` (any of the disc above the terrain and not behind Earth; same as `lit` in `backend/app/analysis.py`)
- Earth visible: `earth.margin[i] >= 0` (same as `linked`)

## Expected user interaction
User scrubs time on the board. When the Sun sets behind terrain (or is eclipsed) its disc on the horizon panel turns from a solid amber dot into a hollow amber ring; likewise the Earth disc turns into a hollow blue ring when it drops below the skyline.

## Done when
- Sun disc is hollow exactly when `sun.fraction[i] == 0`, solid otherwise
- Earth disc is hollow exactly when `earth.margin[i] < 0`, solid otherwise
- `npm run build` passes

## Solution
**Chosen:** `disc()` in `frontend/src/board/Skyline.tsx` takes a `visible` flag. Visible bodies keep the solid `dot()` at `DOT_R * 5`. Hidden ones are a canvas-stroked ring of the same outer radius (line width `DOT_R * 1.5`, inset by half the line so the size doesn't jump). Sun visible = `sun.fraction[i] > 0`, Earth visible = `earth.margin[i] >= 0`.

**Strengths**
- Uses the backend's own visibility values, so the disc agrees with % sunlit, next sunset, comms state and MARGIN, including eclipses (the Sun can be above the skyline yet have `fraction` 0 behind Earth).
- Same colour, size and full opacity, so it stays undithered as style.md requires.

**Limitations**
- The ring is a smooth stroke, not built from grid dots, so it sits slightly off the dot pitch.
- A Sun partly behind terrain (0 < fraction < 1) still shows solid.

**Alternatives considered**
| Option | Why not chosen | Trade-off vs chosen |
|---|---|---|
| Decide visibility in the frontend from `el >= skyline` (as the track dots do) | Ignores eclipses and the Sun's disc size, so it could disagree with the metrics | Simpler, no API fields needed |
| Ring made of grid dots | At ~4.5 px radius too few dots to read as a circle | Would match the dot pitch exactly |
