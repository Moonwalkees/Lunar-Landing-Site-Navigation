# 4.6 Compare: highlight the best value per metric

Status: done
Note: Compare.tsx highlights the best cell per metric row (direction table, ties at display precision); `td.best` style in styles.css.
Owner: Maddie
Source: scope.md > Core 6 Compare
Style: doc/style.md > Components > Board, Colour (best cell uses the palette, no glow)
Depends on: 4.2

## Description
In `Compare.tsx`, highlight the best value in each metric row (higher is better for power/% metrics; lower is better for longest night / longest blackout; Yes beats No for survives).

## Expected user interaction
User pins 2-4 sites; the best cell in each row is highlighted.

## Done when
- Correct direction for every metric; ties highlight all tied cells

## Solution
**Chosen:** `bestIndexes()` in `frontend/src/components/Compare.tsx` uses a per-metric direction table (`BETTER`) to pick the best cell in each row. Those cells get `className="best"`, styled in `frontend/src/styles.css` as `td.best` with `--ok` (fallback `#7BD66B`) and bold text, with no glow.

**Strengths**
- The direction table follows the ticket: higher is better for power, energy, %, battery min and Earth clearance. Lower is better for longest night and longest blackout. Yes beats No for survives. For Next sunset and Next Earthset, the later time is better (compared with `Date.parse`).
- Values are compared after rounding to the one decimal that `formatMetric` displays, so cells that read the same tie and are all highlighted.
- A pure function, so it can be unit tested later without React.

**Limitations**
- A countdown is null when nothing sets in the window, which could mean always up or never up. Null countdowns are skipped rather than ranked.
- A row is only highlighted when at least two pinned sites have a value. Nulls are skipped.
- The `--ok` token isn't on `:root` until 4.8, so the hex fallback is used until then.

**Alternatives considered**
| Option | Why not chosen | Trade-off vs chosen |
|---|---|---|
| Compare raw floats | Two cells showing "12.3" could disagree on which is best | Exact, but not consistent with what the user sees |
| Highlight with `--selected` or a fill | `--selected` means the selected site, and fills are used for the selected row | Stronger, but would clash with board meanings in style.md |
