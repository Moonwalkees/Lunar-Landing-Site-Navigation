# 4.15 Console: background shows lit vs shadow, text never dimmed

Status: done
Owner: Maddie
Source: doc/style.md > Rendering rules (Dim by dither), Site console; user request 2026-11-15
Note: superseded by 4.17 (whole page). `.console.shaded` changed only the background, instead of desaturating and darkening the whole panel (`board.css`, style.md).

## Description
The site console on the map (name, status, % sunlit, % contact, max dark, SURFACE VIEW) was desaturated and darkened as a whole when the selected site was in shadow. Keep the contents at full brightness at all times. Show lit vs shadow only through the panel background: slightly lighter when lit, darker when in shadow.

## Expected user interaction
User selects or scrubs a site into shadow. The console's text and colours stay the same, and the panel background drops from a dark warm grey to near-black. When the site is lit again, the background lightens.

## Done when
- No filter, opacity or saturation change on the console contents
- Background is lighter when the site is lit, darker when it is in shadow
- style.md matches
- `npm run build` passes

## Solution
**Chosen:** In `frontend/src/board/board.css`, `.console` uses `--ash-dim` mixed 45% into `--space` (88% opaque) as its background. `.console.shaded` swaps that background to `--space` (88% opaque). The `filter: saturate(.2) brightness(.75)` is gone. The `shaded` flag is unchanged in `BoardApp.tsx` (site state `dark` or `comms`). The change steps over `.6s steps(3)`, in line with style.md's hard-step motion for status changes.

**Strengths**
- Uses existing tokens only. Readouts keep their `--sun` / `--earth` / `--regolith` colours, so the numbers stay legible.

**Limitations**
- The difference is deliberately subtle, so it can be hard to see over bright terrain behind the translucent panel.

**Alternatives considered**
| Option | Why not chosen | Trade-off vs chosen |
|---|---|---|
| `--umbra` as the lit background | It is the "shadow" token, and its blue tint reads as the wrong meaning | Already in the palette for fills |
