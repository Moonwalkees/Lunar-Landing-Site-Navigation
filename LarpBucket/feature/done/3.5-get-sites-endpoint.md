# 3.5 GET /sites

Status: done
Owner: Aiken
Source: scope.md > Core 1 Observer placement, tech-stack.md > Stack (API)

## Description
Create `backend/app/main.py` (FastAPI) with CORS for the frontend dev origin, and `backend/app/sites.py` with the preset list (Artemis III regions, Apollo, CLPS targets: name, lat, lon). `GET /sites` returns it.

## Expected user interaction
`uvicorn app.main:app --reload`, then `GET http://localhost:8000/sites` returns JSON presets.

## Done when
- Endpoint returns the list; frontend dev origin allowed by CORS

Note: done. `app/main.py` (FastAPI, CORS for the Vite dev origin, more via `FRONTEND_ORIGINS`) and `app/sites.py` with the same five presets as the frontend placeholder.

## Solution
**Chosen:** `backend/app/main.py` creates the FastAPI app with CORS for the Vite dev origin (more through `FRONTEND_ORIGINS`), and `backend/app/sites.py` holds five presets. `GET /sites` returns them.

**Strengths**
- Same five presets as the frontend placeholder, so 4.3 is a straight swap.

**Limitations**
- The Artemis III entries are single representative points inside each region, not official landing coordinates.
- The frontend still uses its own copy until 4.3.

**Alternatives considered**
Only one sensible approach for a fixed list this small.
