Owner: Aiken

Style: doc/style.md > Components > Dot chart, Time dock, Touch and mobile (Plotly vs dot-matrix charts is undecided, see Open decisions 2)

Note: done (marked done by Maddie, 2026-11-15). The board UI's dot chart (`frontend/src/board/DotChart.tsx`) and time dock (`TimeDock` in `Panels.tsx`) cover the time series and scrubber; the classic UI keeps Aiken's `TimeSeries.tsx`. Plotly vs custom charts settled as custom for the board (doc/style.md).

## Description
Replace the placeholders in `TimeSeries.tsx` with Plotly charts for power, battery and comms state over the window (shared time axis). Show a vertical line at the scrubber time, which is shared with the panorama.

## Expected user interaction
User drags the scrubber; the vertical line moves across all three charts and the panorama markers move in sync.

## Done when
- One scrubber drives panorama and all time series

## Solution
**Chosen:** Custom canvas charts, no Plotly. The classic UI uses `frontend/src/components/TimeSeries.tsx` (Aiken), which has Sun, Earth, power and battery rows, a playhead, play/pause with loop and speed, and drag/hover. The board UI uses `frontend/src/board/DotChart.tsx`, the same bands as dot-matrix cells, scrubbed by the shared time index from `TimeDock` (`frontend/src/board/Panels.tsx`).

**Strengths**
- One shared time index drives every panel, the map and the charts, so scrubbing stays in sync.
- Canvas charts match the dot-matrix style and avoid Plotly's weight in the board build.

**Limitations**
- Two chart implementations to maintain (classic and board).

**Alternatives considered**
| Option | Why not chosen | Trade-off vs chosen |
|---|---|---|
| Plotly time series | Doesn't fit the dot-matrix style, and it is heavy | Built-in zoom and hover |
