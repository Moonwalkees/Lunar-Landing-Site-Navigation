# 7.4 Eclipse alert

Status: done
Owner: Aiken
Source: Extension features (team brainstorm, not yet in scope.md)
Related: feature/done/6.1-lunar-eclipse-sun-occultation.md (eclipse already reduces power in the model)
Note: done. Eclipses are marked in red on both UIs' charts, named in the readouts, and a button jumps to the next one; the 3D view shows the Earth covering the Sun (BUG-011). Shared logic in `frontend/src/eclipses.ts`.

## Description
Mark eclipses with a special marker on the graphs, and show them in the 3D render. Eclipses may affect some key factors; 6.1 already handles the power effect.

## Expected user interaction
When the window contains an eclipse, the time series shows an eclipse marker and the render shows the eclipse when the scrubber is on it.

## Done when
- Eclipse periods are marked on the time series
- Eclipse is visible in the 3D render

## Solution
**Chosen:** `frontend/src/eclipses.ts` finds the runs of time steps where `sun.behindEarth` (from 6.1) is above zero, with each run's peak. The board marks them in `--selected` across the SUN band of the dot chart (`board/DotChart.tsx`, three dot columns wide so a few hours show in a year), adds ECLIPSE to the legend, and shows a line under the chart: "Eclipse now · 33% of the Sun behind the Earth", or "Next eclipse · 2027-08-17 08:00 · up to 33%" with a GO TO ECLIPSE button that moves the scrubber to the peak. The classic time series marks the Sun row in red and has a Next eclipse button (`components/TimeSeries.tsx`). Both rover readouts add an eclipse line while one is under way. The board's 3D view has its own GO TO ECLIPSE button, which moves the time to the peak and turns the 3D camera toward the Sun, keeping the view (orbit or surface) and the zoom (Unity `Bridge.LookTowardSun`; the camera glides there over 1.6 s), and a red ECLIPSE badge while one is under way (`board/Detail3D.tsx`). The 3D view draws the Earth over the Sun (BUG-011).

**Strengths**
- No new backend work: it reads the occultation the analysis already returns.
- The demo's eclipse, 17 Aug 2027 at Malapert, is one click from anywhere in the window.
- Marks are found per chart column, so even a two-hour eclipse in a year-long window shows.

**Limitations**
- At the board's 2 h steps the peak can fall between samples (33% shown, 43% at 1 h steps).
- One marker colour for any eclipse depth; the depth is in the text, not the mark.
- Only eclipses inside the analysed window are found.

**Alternatives considered**
| Option | Why not chosen | Trade-off vs chosen |
|---|---|---|
| A separate ECLIPSE band on the board chart | Another full band for a few hours a year | Depth could be shown as height |
| Backend list of eclipses in the response | The frontend can derive it from data it already has | One place for the rule |
| 3D GO TO ECLIPSE switching to surface view and zooming the lens onto the Sun | Changed what the viewer was looking at; asked to keep the view and zoom | The Earth and Sun fill the picture |
| 3D GO TO ECLIPSE moving only the time | The eclipse could be behind the camera | Camera never moves |
