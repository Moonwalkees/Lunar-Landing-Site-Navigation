# 4.8 Apply style tokens and type to the shell

Status: done
Owner: Maddie
Source: doc/style.md > Colour, Type, Dot grid and pixel size, Rendering rules
Style: doc/style.md
Depends on: 4.1
Note: done. Delivered by the board UI (4.12): tokens on `:root` in `frontend/src/board/board.css` and `palette.ts`, Doto / Geist Mono type, the dot grid and the rendering rules from doc/style.md.

## Description
Restyle the existing placeholder shell in `frontend/` to the dot-matrix board style: replace the colour tokens in `styles.css` with the ones in `doc/style.md`, load Doto and Geist Mono, set `tabular-nums`, make panels, buttons and inputs square (no border radius), and use Doto for all board text at 18 px or larger. Do not add the 3D map, the board table or new panels here; those wait on the open decisions in `doc/style.md`.

## Expected user interaction
User opens the app and sees the same panels as before, now on a black background with Doto type, the new palette and square chrome.

## Done when
- Tokens match `doc/style.md > Colour`
- Doto is used for headings, readouts, buttons and labels, never below 18 px
- No border radius anywhere
- Layout still works at 400 px with no horizontal scroll
- `npm run build` passes

## Solution
**Chosen:** Applied in the board UI rather than the old shell. `frontend/src/board/board.css` defines the doc/style.md colour tokens on `:root` (plus `--bg` for the lit / shadow page tint). `frontend/src/board/palette.ts` mirrors them for canvas and WebGL. Type is Doto for the board and Geist Mono for small captions. The dot-grid pitch is `PITCH` in `DotChart.tsx`.

**Strengths**
- Every board panel, chart and the 3D map read the same tokens, so the theme stays consistent.

**Limitations**
- The classic UI (`App.tsx`, `styles.css`) keeps its original look. It was left unchanged on purpose.

**Alternatives considered**
| Option | Why not chosen | Trade-off vs chosen |
|---|---|---|
| Restyle the classic shell in place | Superseded by building the approved board design as its own UI (4.12) | One UI instead of two |
