# 4.30 Remove the classic UI

Status: done
Owner: Aiken
Source: user request, 2026-11-15 (before submission)
Note: done. The board is the only frontend; the classic panel UI, its CLASSIC VIEW switch and Plotly are gone.

## Description
The app shipped two frontends: the dot-matrix board (default) and the original "classic" panel layout, switched by a CLASSIC VIEW button. Only the board is presented and maintained, so remove the classic UI entirely.

## Expected user interaction
The board opens as before. There is no CLASSIC VIEW button; an old `?ui=classic` link opens the board.

## Done when
- No classic UI code, styles or switch remain in the frontend
- Plotly is no longer a dependency
- The board, its 2D and 3D views, the mission card and saved setup work as before

## Solution
**Chosen:** `frontend/src/main.tsx` loads the board directly (still after `guardTextInput()`). Deleted `App.tsx`, `classic.tsx`, `styles.css`, `UiSwitch.tsx`, `uiChoice.ts` and the classic-only components (`Compare`, `MetricCards`, `Panorama`, `RoverStatus`, `SiteForm`, `TerrainView`, `TimeSeries`); the files each UI imports were mapped first, so everything the board uses (`TerrainMap`, `TerrainView3D`, `ForecastLegend`, `rover.ts`, `eclipses.ts`, `persist.ts`, ...) stays. `persist.ts` loses the classic form's load/save; `clearSaved()` still removes the old classic key. Removed `plotly.js`, `react-plotly.js` and `@types/plotly.js`, Vite's Plotly pre-bundling, and the `VITE_UI` build argument from `frontend/Dockerfile`. README, tech-stack.md, style.md and 2d-view.md updated.

**Strengths**
- One UI to test and present; the build no longer ships Plotly (several MB).
- Old links with `?ui=` still open the app.

**Limitations**
- Done tickets that describe classic work stay as history; their files no longer exist.
- A saved "classic" choice in a browser's storage is simply ignored.

**Alternatives considered**
| Option | Why not chosen | Trade-off vs chosen |
|---|---|---|
| Hide the CLASSIC VIEW button but keep the code | Dead code and Plotly still built and shipped | Easy to bring back |
| Keep classic for phones | The board already has a phone layout | A simpler page on small screens |
