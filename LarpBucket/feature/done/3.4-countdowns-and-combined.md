# 3.4 Countdowns and power + comms %

Status: done
Owner: Aiken
Source: scope.md > Core 4 Metrics (countdown, % both)

## Description
Add next sunset / next Earthset (first time after the scrubber/start time where the Sun disc fraction drops to 0 or Earth margin drops below 0) and % time with both power (f > 0) and comms (margin ≥ 0).

## Expected user interaction
Caller gets two ISO timestamps (or null if no event in the window) and a percentage.

## Done when
- Returns null cleanly when the event never happens in the window

Note: done. Next sunset, next Earthset and % with both are computed in `app/analysis.py`; the timestamps are null when the event never happens in the window.

## Solution
**Chosen:** In `backend/app/analysis.py`: `_next_drop` returns the first time the Sun fraction falls to 0 (next sunset) or the Earth margin falls below 0 (next Earthset), and `pctPowerAndComms` is the share of steps with both.

**Strengths**
- Uses the same lit and linked arrays as the other metrics, so the numbers cannot disagree.
- Returns null when the event never happens in the window; the cards show a dash.

**Limitations**
- Counted from the start of the window, not from the scrubber time. The time-series panel shows its own 'sets in' from the scrubber.
- Accurate to one time step.

**Alternatives considered**
| Option | Why not chosen | Trade-off vs chosen |
|---|---|---|
| Compute only in the frontend | The metric cards are filled from the backend response | Would follow the scrubber |
| Interpolate the crossing time between steps | Extra code for minutes of gain at a 1 h step | Finer timestamps |
