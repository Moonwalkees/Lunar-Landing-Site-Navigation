# 2.2 Skyline for one south pole site

Status: done
Owner: Aiken
Source: scope.md > Core 3 Horizon panorama, tech-stack.md > Stack (Horizon algo)

## Description
Add `skyline(lat, lon) -> (az[720], el[720])` in `horizon.py`. For each 0.5° azimuth, march outward along the surface (fine steps near, coarser far, out to ~150 km), sample heights with 2.1, correct for lunar curvature (R = 1737.4 km), and keep the max elevation angle. Observer sits on the terrain plus a small mast height (e.g. 2 m).

## Expected user interaction
Caller passes a site; gets a 360° skyline. A quick matplotlib plot for Shackleton/Connecting Ridge shows a believable horizon.

## Done when
- Returns 720 values in ~1-2 s
- Plot looks plausible for a south pole rim site

Note: done. `skyline(lat, lon)` returns 720 values in about 0.2 s: 20 m heights within 12 km, the polar map at 160 m beyond that, the global map elsewhere, out to 150 km, observer 2 m up.

## Solution
**Chosen:** `skyline(lat, lon)` in `backend/app/horizon.py` returns 720 azimuths and the highest terrain elevation angle in each. It marches outward from the site: 20 m steps for the first 12 km, 160 m steps on the polar map beyond that, the global map elsewhere, out to 150 km, with the curvature drop applied. The observer is on the ground plus a 2 m mast. `skyline_at(az, ...)` interpolates the skyline at any azimuth.

**Strengths**
- About 0.2 s per site, so `/analyze` needs no cache.
- Fine steps where a small rise matters (close to the site), coarse steps where it does not.
- Agrees with an independent calculation made earlier from LOLA 80 m data: mean difference +0.015 degrees, RMS 0.106 degrees.

**Limitations**
- Stops at 150 km. A very high peak further away is missed.
- 0.5 degree azimuth bins: a narrow notch in the skyline is averaged out.
- Inherits the 20 m map's limit on narrow crests (see 2.1).
- Mast height is fixed at 2 m (`MAST_M`); it is not a request field.

**Alternatives considered**
| Option | Why not chosen | Trade-off vs chosen |
|---|---|---|
| 20 m steps all the way out | About ten times slower for no visible change far away | Simpler code |
| Precomputed horizon maps per site | Only works for fixed sites and needs storage | Instant responses |
| Ray casting against a terrain mesh | Much more code, same answer | Reusable for other viewpoints |
