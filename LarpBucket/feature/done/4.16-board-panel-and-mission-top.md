# 4.16 Board in a bordered panel, mission window at the top

Status: done
Owner: Maddie
Source: doc/style.md > Layout; user request 2026-11-15
Note: done. The ranked board is wrapped in a captioned `.panel`, and `Mission` moves to just below the lamp strip (`Board.tsx`, `BoardApp.tsx`, `board.css`, style.md).

## Description
The ranked site board was the only content block on the board UI without the bordered, captioned panel the side panels use. Put it in one. Move the mission window controls (start date, days, step) from the bottom of the page to the top, directly under the lamp strip (site / lit / Earth AOS / lit + AOS counts).

## Expected user interaction
Under the map, the user first sees the lamps, then the Mission window panel. Next comes the ranked board in a bordered panel captioned "SITES · RANKED", next to the chart panels.

## Done when
- The board has the same border and caption style as the other panels
- Mission window sits directly below the lamp strip
- style.md layout list matches
- `npm run build` passes

## Solution
**Chosen:** In `frontend/src/board/Board.tsx`, the board `<section>` gets `className="panel"` and a `cap` caption "Sites · ranked". In `frontend/src/board/BoardApp.tsx`, `<Mission>` moves from the bottom of `.wrap` to directly after `<Lamps>`. In `frontend/src/board/board.css`, `.mission` padding becomes `8px 16px` so the board panel's caption below has room. `doc/style.md` > Layout now lists the mission window as item 3.

**Strengths**
- Reuses the existing `.panel` / `.cap` styles, with no new CSS for the border.

**Limitations**
- Follow-up (user request): the board's regolith top rule (`.board { border-top }`) was removed, since the panel border now frames the table. Panel captions (`.cap`) are black only below the border line (`linear-gradient(transparent 7px, --space 7px)`), so the page tint and static show behind their top half.

**Alternatives considered**
Only one sensible approach. This was a direct user request.
