# 3.3 Comms metrics

Status: done
Owner: Tam Nguyen
Source: scope.md > Model (comms margin), Core 4 Metrics (Comms)

## Description
Add comms margin `earth_el - skyline_el(earth_az)` in radians, with states blocked (< 0), marginal (< 0.5° in radians), clear. Report current Earth clearance, % time visible (margin ≥ 0) and longest blackout in hours (reuse `longest_run` from 3.2).

## Expected user interaction
Caller gets a comms state per step plus the three comms metrics.

## Done when
- State thresholds unit tested

Note: done. Added typed communications metrics, vectorized margin and state helpers, and blackout summaries.

## Solution
**Chosen:** `backend/app/model.py` defines `CommsMetrics`; `backend/app/utils.py` calculates margin, state, and summaries in radians; `backend/app/constants.py` defines the 0.5° marginal threshold in radians.

**Strengths**
- Reuses `longest_run` so blackout duration follows the battery module's time-step semantics.
- Keeps all calculation thresholds in radians, matching the model math.

**Limitations**
- The current clearance comes from the caller-selected time index.

**Alternatives considered**
Only this structure preserves the existing schema, constants, and helper boundaries.
