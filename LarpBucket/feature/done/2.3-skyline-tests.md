# 2.3 Skyline sanity tests

Status: done
Owner: Aiken
Source: tech-stack.md > Verification

## Description
Add `backend/tests/test_horizon.py`: a flat synthetic DEM gives a skyline ≈ 0° minus the curvature dip; a single synthetic peak shows up at the right azimuth with the expected elevation angle.

## Expected user interaction
Developer runs `pytest`; tests pass.

## Done when
- Both tests pass without needing the real DEM files

Note: done. `tests/test_horizon.py`: flat terrain gives the curvature dip, a single peak appears at its azimuth with the expected elevation; neither needs the real maps.

## Solution
**Chosen:** `backend/tests/test_horizon.py` passes a synthetic height function into `skyline` (its `height_fn` argument): flat ground gives the curvature dip in every direction, and a single peak appears at its azimuth with the expected elevation angle.

**Strengths**
- Needs no downloaded data, so it runs anywhere.
- Tests the geometry (azimuth convention, curvature) on cases with a known answer.

**Limitations**
- Does not exercise reading the real maps. `tests/test_real_data.py` does, and skips when `backend/data` is empty.

**Alternatives considered**
| Option | Why not chosen | Trade-off vs chosen |
|---|---|---|
| Test only against the real maps | Needs 400 MB of data and has no exact expected answer | Would catch file-reading mistakes |
