## Description
The time dock's readout was captioned "SCRUB TIME · UTC". Caption it "TIME (UTC)" instead, left-aligned so it sits at the top-left above the date. The readout itself (date and time) is unchanged.

## Expected user interaction
The bottom dock shows "TIME (UTC)" above the date and time, e.g. `2026-12-10 07:00`.

## Done when
- Caption reads "TIME (UTC)"
- Caption is left-aligned over the date on desktop
- `npm run build` passes

## Solution
**Chosen:** Changed the caption text in `TimeDock` in `frontend/src/board/Panels.tsx`. The `.mono` class still uppercases it. `.t-read` in `frontend/src/board/board.css` changed from `text-align: right` to `left`, so on desktop the caption starts at the date's left edge. On phones it was already inline to the left.
