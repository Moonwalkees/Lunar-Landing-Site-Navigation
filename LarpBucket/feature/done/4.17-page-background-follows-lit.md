# 4.17 Whole page background follows the selected site's sunlight

Status: done
Owner: Maddie
Source: doc/style.md > Rendering rules (Dim by dither), Site console; user request 2026-11-15
Supersedes: 4.15 (console-only background)
Note: done. `html.lit` sets a lighter `--bg` used by the page, panel captions, inputs, dock and console (`board.css`, `BoardApp.tsx`, style.md).

## Description
Ticket 4.15 changed only the console card's background with lit vs shadow. Apply it to the whole page instead: slightly lighter while the selected site is in sunlight, near-black while it's in shadow. Text keeps full brightness.

## Expected user interaction
User scrubs time or picks another site. When the selected site goes into shadow, the whole page background fades darker. When it is lit again, it fades lighter. The console card follows the page instead of changing on its own.

## Done when
- Page, panel captions, inputs, time dock and console share one background that follows lit vs shadow
- No dimming of text
- style.md matches
- `npm run build` passes

## Solution
**Chosen:** `frontend/src/board/board.css` adds a `--bg` token (default `--space`) and `html.lit { --bg: color-mix(--ash-dim 45%, --space) }`. `html`, `body`, `.cap`, `.field input`, `.dock` and `.console` (88% opaque) use `--bg`, fading over `1.2s ease-in-out` (smooth, per the user; style.md lets light ease smoothly). The fade is turned off under reduced motion. `BoardApp.tsx` toggles `html.lit` in an effect when the selected row's state is `both` or `sunonly`. The `shaded` class and `.console.shaded` rule are removed.

Follow-up (user request): boxes are always solid black. `.panel`, `.lamp`, `.cap`, `.field input` and `.console` (88% opaque) use `--space`, so the lit tint and the 8.3 LOS static only show in the gaps between boxes. The page, `html`/`body` and `.dock` still use `--bg`.

**Strengths**
- A single token, so captions and inputs that punch through panel borders always match the page behind them.

**Limitations**
- The hero 3D map keeps its black WebGL clear colour. Only the page around it changes.
- `--space` is unchanged, so dark text on filled lamps and chips stays pure black.

**Alternatives considered**
| Option | Why not chosen | Trade-off vs chosen |
|---|---|---|
| Override `--space` itself when lit | Also changes text-on-fill colours, and canvases only read it at draw time | One less token |
