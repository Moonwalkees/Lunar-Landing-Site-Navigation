# 4.19 Remove the NOW sort chip from the board

Status: done
Owner: Maddie
Source: doc/style.md > Board; user request 2026-11-15
Note: done. NOW chip, `"now"` sort key and `STATE_RANK` removed (`Board.tsx`, `data.ts`); style.md updated.

## Description
The board's sort bar has a NOW chip that sorts by the current lit/comms state, then score. Remove it. The SCORE, SUN, COMMS and BOTH sorts stay. The LIT and COMMS "right now" columns stay.

## Expected user interaction
The sort bar reads SCORE · SUN · COMMS · BOTH. Clicking any of these ranks the board as before.

## Done when
- No NOW chip in the sort bar
- `"now"` sort key and its ranking code are gone from `frontend/src/board/data.ts`
- style.md matches
- `npm run build` passes

## Solution
**Chosen:** Removed `{ k: "now" }` from `SORTS` in `frontend/src/board/Board.tsx`, and `"now"` from `SortKey`, its `rankRows` case and the now-unused `STATE_RANK` in `frontend/src/board/data.ts`. Updated the sort-chips line in `doc/style.md > Board`.

**Strengths**
- Deletes code only. The type checker catches any remaining `"now"` sort key.

**Limitations**
- The `.now` CSS class on the LIT / COMMS status cell is unrelated to sorting and stays.

**Alternatives considered**
Only one sensible approach. This was a direct user request.
