# 4.28 Mark sites that have no 3D terrain

Status: done
Owner: Aiken
Source: follows 4.9 (3D terrain view) and 4.12 (dot-matrix board UI). Requested by the 3D view's owner.
Note: done. Sites outside the four 3D terrain areas (the Apollo presets, most custom sites) carry a `2D ONLY` tag on the board, and their 3D tabs are off in both UIs.

## Description
The 3D views only have terrain around Connecting Ridge, Shackleton rim, Shackleton crater and Malapert Massif. For any other site the user found out only after opening the 3D view, which showed a note where the terrain should be. Say so before they get there.

## Expected user interaction
- Board: an Apollo row shows `2D ONLY` after its name. Selecting it, the console says `2D ONLY · NO 3D TERRAIN HERE` and its button reads `2D MAP VIEW`. The detail view opens on the 2D MAP tab with ORBIT and SURFACE disabled.
- Classic: with such a site selected, the Orbit view and Surface view buttons are disabled and a line under the panel says the map is 2D only and where 3D terrain exists.

## Done when
- Both Apollo presets are marked in both UIs
- No 3D download starts for a site with no 3D terrain
- The three south pole presets are unchanged

## Solution
**Chosen:** Every place asks `terrainTileFor(lat, lon)` from `frontend/src/terrain.ts`, the same test the 3D view uses. `board/Board.tsx` and `board/BoardApp.tsx` add the `.tag2d` tag; `board/Detail3D.tsx` opens on the 2D map and disables the 3D tabs; `components/TerrainView.tsx` disables the 3D buttons and stays on the bird's-eye map.

**Strengths**
- One rule in one file, so the tag and the 3D view cannot disagree, and a new terrain area is picked up everywhere.
- The Unity build is never downloaded for a site that cannot use it.

**Limitations**
- The classic site dropdown itself is not marked; the hint is in the terrain panel.
- The row menu's action is still called SURFACE VIEW for these sites; it opens the 2D map.

**Alternatives considered**
| Option | Why not chosen | Trade-off vs chosen |
|---|---|---|
| Leave the 3D tabs on and show the note inside the 3D view | It downloads 27 MB to show a message | Nothing to change |
| Build 3D terrain for the Apollo sites | Needs a different map projection, new terrain and a rebuild | Apollo in 3D |
