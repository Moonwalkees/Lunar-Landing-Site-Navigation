# 2.1 DEM height sampler

Status: open
Owner:
Source: tech-stack.md > Stack (Terrain, Horizon algo), Build order 2

## Description
In `backend/app/horizon.py`, add `height_at(lat, lon)` (vectorised) that returns terrain height in metres with bilinear interpolation. Use the 20 m polar DEM where it covers the point, otherwise the global `LDEM_64`.

## Expected user interaction
Caller passes arrays of lat/lon; gets heights back. No visible UI.

## Done when
- Polar points read from the 20 m DEM, others from the global DEM
- Heights agree between the two DEMs within ~ tens of metres where they overlap
