# 2.1 DEM height sampler

Status: open
Owner:
Source: tech-stack.md > Stack (Terrain, Horizon algo), Build order 2

## Description
In `backend/app/horizon.py`, add `height_at(lat, lon)` (vectorised) that returns terrain height in metres with bilinear interpolation. Use the 20 m polar DEM where it covers the point, otherwise the global `LDEM_64`.

DEM notes (from 1.3): files are `backend/data/dem/ldem_85s_20m_crop.tif` (south polar stereographic, 20 m, cropped to the south pole presets + 30 km) and `backend/data/dem/ldem_64.tif` (equirectangular, `lon_0=180`, 473.8 m, whole Moon). Both are int16: multiply by `ds.scales[0]` (0.5) to get metres above the 1737.4 km sphere. The global raster's edges are at lon 0/360, so lon exactly 0 maps to column -1 by rounding: wrap column indices modulo the width (and interpolate across the seam). Use the polar crop only inside its bounds, not everywhere south of -85°.

## Expected user interaction
Caller passes arrays of lat/lon; gets heights back. No visible UI.

## Done when
- Polar points read from the 20 m DEM, others from the global DEM
- Heights agree between the two DEMs within ~ tens of metres where they overlap
