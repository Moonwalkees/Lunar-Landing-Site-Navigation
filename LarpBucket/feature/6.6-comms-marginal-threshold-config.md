# 6.6 Configurable comms margin threshold

Status: open
Owner:
Source: scope.md > Model (Comms margin), Core 4 Metrics (Comms)
Priority: low
Depends on: 3.3

## Description
The marginal threshold (0.5°) in 3.3 is arbitrary. Make it a named parameter (default 0.5°) accepted by the comms functions and optionally by `POST /analyze`. Document where the default comes from, or mark it as a placeholder to confirm with the team. A full link budget stays out of scope.

## Why it is useful
Antenna masks and terrain-diffraction margin vary by lander and the right clearance is a mission choice, not a constant of nature.

## Impact of not having it
Blocked/marginal/clear splits and "% time visible" rest on an unjustified number. At the poles Earth sits within a few degrees of the horizon, so the threshold materially changes the comms percentages.

## Expected user interaction
Default behaviour is unchanged. An advanced option lets the caller set the threshold and see the states and metrics update.

## Done when
- Threshold is a parameter with the default value unchanged
- Tests show state changes when the threshold changes
- Default's rationale noted in scope.md or tech-stack.md
