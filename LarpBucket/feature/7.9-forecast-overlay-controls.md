# 7.9 Forecast overlay controls on the 2D map

Status: in-progress
Owner: Tony Pham
Source: Extension feature (user request: near-future power/comms change heatmap)
Depends on: 7.7, 7.8

## Description
Add the forecast overlay to `frontend/src/components/TerrainMap.tsx`, which serves both UIs.

Controls, in a compact row next to `viewButtons`:
- Layer: Off / Power Δ / Comms Δ. Default is Off, so the map is unchanged unless the user turns it on.
- Mode: Δ / Worst dip
- Horizon: 3 / 6 / 12 steps. Default is 6. The label shows hours (`k × stepHours`).

Wiring:
- New `TerrainMap` props: `analysis` and `index`.
- Pass them from `board/Detail3D.tsx`, which already has `analysis` and `index`.
- Pass them from `App.tsx` (`tracks`, `index`) through `components/TerrainView.tsx`.

Hover: the existing hover readout also shows the forecast, e.g. "POWER 0.82 → 0.10 in 12 h (dips to 0.00 at +6 h)".

## Expected user interaction
The user opens the 2D map and picks Power Δ or Comms Δ, then scrubs or plays. The heatmap shows which ground is about to gain or lose the Sun or Earth link over the chosen span. The user hovers a cell for the exact numbers. Sun and Earth arrows and the site marker stay on top.

## Done when
- Overlay works in the board UI (2D MAP tab) and the classic UI
- Default Off leaves the map exactly as before
- Hover readout shows now, at `i+k`, and the worst dip
- Carried over from 7.7, which could not be checked without something drawing the overlay: in a real browser, scrubbing and playback at a polar site stay smooth with the overlay on, and a cold jump fills in within about 150 ms
