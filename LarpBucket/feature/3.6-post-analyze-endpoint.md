# 3.6 POST /analyze

Status: open
Owner:
Source: scope.md > Core 2-5, tech-stack.md > Stack (API)

## Description
`POST /analyze` takes `{lat, lon, startDate, days, stepHours}` and returns skyline (az, el), time array, Sun/Earth tracks, power, battery, comms state and the metrics object. Field names must match `frontend/src/types.ts` (`Metrics`). No caching.

## Expected user interaction
Frontend sends a site and window; gets everything needed for all panels in one response.

## Done when
- Response validated by pydantic models
- One-month, 1 h step request returns in a few seconds
