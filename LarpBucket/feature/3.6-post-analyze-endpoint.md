# 3.6 POST /analyze

Status: open
Owner:
Source: scope.md > Core 2-5, tech-stack.md > Stack (API)

## Description
`POST /analyze` takes `{lat, lon, startDate, days, stepHours}` and returns skyline (az, el), time array, Sun/Earth tracks, power, battery, comms state and the metrics object. Field names must match `frontend/src/types.ts` (`Metrics`). No caching.

Ephemeris notes (from 1.2): call `ephemeris.load_kernels()` in the FastAPI lifespan so no request loads kernels. `sun_earth_azel` takes UTC strings and returns numpy arrays in **radians** (`np.degrees(...).tolist()` if the frontend expects degrees); it raises `ValueError` for a bad lat/lon and SPICE errors for unparseable times, so map those to 422. SPICE calls are serialized by `ephemeris.SPICE_LOCK`.

## Expected user interaction
Frontend sends a site and window; gets everything needed for all panels in one response.
