# 7.8 Diverging heatmap paint and legend

Status: open
Owner:
Source: Extension feature (user request: near-future power/comms change heatmap). Follows doc/style.md for colour.
Depends on: 7.7

## Description
Draw a change field (−1 to +1) over the existing 2D map without hiding the terrain:

- Add `paintDelta(base: ImageData, delta: Float32Array, opacity)` in `frontend/src/terrain2d.ts`.
  - It blends a diverging scale over the relief image: red for losing, transparent for no change, teal/blue for gaining.
  - It uses the same 2× bilinear upsample as `paint()`.
  - Values with |Δ| < 0.02 stay transparent, so noise doesn't tint the map.
- Legend: a gradient bar labelled "losing … gaining", the body (POWER / COMMS), the mode (Δ / WORST DIP) and the span ("next 12 h", or "next 4 h (end of window)").
- Take colours from `board/palette.ts` tokens where possible. The ramp must stay readable for colour-blind viewers.

## Expected user interaction
With the overlay on, the user sees red where power or comms will drop over the next k steps and blue where it will improve. A legend explains the colours and the time span.

## Done when
- Heatmap is readable over both sunlit and shadowed ground
- Zero change is fully transparent
- Legend shows body, mode and span in hours
- `npm run build` passes
