# 3.5 GET /sites

Status: open
Owner:
Source: scope.md > Core 1 Observer placement, tech-stack.md > Stack (API)

## Description
Create `backend/app/main.py` (FastAPI) with CORS for the frontend dev origin, and `backend/app/sites.py` with the preset list (Artemis III regions, Apollo, CLPS targets: name, lat, lon). `GET /sites` returns it.

## Expected user interaction
`uvicorn app.main:app --reload`, then `GET http://localhost:8000/sites` returns JSON presets.

## Done when
- Endpoint returns the list; frontend dev origin allowed by CORS
