# 2.2 Skyline for one south pole site

Status: open
Owner:
Source: scope.md > Core 3 Horizon panorama, tech-stack.md > Stack (Horizon algo)

## Description
Add `skyline(lat, lon) -> (az[720], el[720])` in `horizon.py`. For each 0.5° azimuth, march outward along the surface (fine steps near, coarser far, out to ~150 km), sample heights with 2.1, correct for lunar curvature (R = 1737.4 km), and keep the max elevation angle. Observer sits on the terrain plus a small mast height (e.g. 2 m).

## Expected user interaction
Caller passes a site; gets a 360° skyline. A quick matplotlib plot for Shackleton/Connecting Ridge shows a believable horizon.

## Done when
- Returns 720 values in ~1-2 s
- Plot looks plausible for a south pole rim site
