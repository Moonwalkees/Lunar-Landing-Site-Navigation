Status: open

## Description
Add comms margin `earth_el - skyline_el(earth_az)`, with states blocked (< 0°), marginal (< 0.5°), clear. Report current Earth clearance, % time visible (margin ≥ 0) and longest blackout in hours (reuse `longest_run` from 3.2).

## Expected user interaction
Caller gets a comms state per step plus the three comms metrics.
